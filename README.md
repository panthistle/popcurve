### PopCurve v1.8

Curves generator/animator add-on for Blender. Developed and tested on Blender 3.6 LTS and 4.2 LTS.  
Latest update: 12-Feb-2025  


### Download and Install

To download the add-on:  
- Click on the 'addon' directory
- Click on 'PTDBLNPOPC.zip', select 'Download raw file' and save the zip file to your hard drive.  

To install the add-on in Blender:
- Start Blender and open the 'Preferences' window from the 'Edit' menu.  Select the 'Add-ons' tab.
- If you have installed a previous version/update of PopCurve, disable and remove it before installing this version.
- Click 'Install from Disk...', find and select the downloaded 'PTDBLNPOPC.zip' file, then click 'Install Add-on'.
- Enable the add-on by ticking the checkbox next to its name.  


### Usage

The best way to find out what the add-on can do for you is to experiment with it. There are several sample files to  
get you started and tooltips if you hover you mouse over any of the command buttons in the user interface.
