### About

Curves generator/animator add-on for Blender. Developed and tested on Blender 3.6 LTS.  
Latest update: 11-Nov-2024  


### Download and Install

To download the add-on:  
- Click on the 'addon' directory
- Click on 'PTDBLNPOPC.zip', select 'Download raw file' and save the zip file to your hard drive.  

To install the add-on in Blender:
- Start Blender and open the 'Preferences' window from the 'Edit' menu.  Select the 'Add-ons' tab.
- If you have installed a previous version/update of PopCurve, disable and remove it before installing this version.
- Click 'Install...', find and select the downloaded 'PTDBLNPOPC.zip' file, then click 'Install Add-on'.
- Enable the add-on by ticking the checkbox next to its name.  


### Usage

The best way to find out what the add-on can do for you is to experiment with it. All the command buttons,  
selection lists and input fields on the interface include tooltips of their function. If you are comfortable  
using Blender, you should not have any problem with PopCurve.  
For more information, check out the [Demo Video](https://www.youtube.com/watch?v=5YuJ9eQYwVE) and the [User Guide](https://panthistle.github.io/pdfs/PCUG18.pdf)
